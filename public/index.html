Add :::accent to a node to paint it bunny orange, e.g. B[Edge Script]:::accent, or :::pill for a light label node. In Clean, extra lines become pills: C["CDN cache<br>match | put"]. Tint edge labels with |on hit:::green| or |on miss:::orange|. Add a headline with --- title: … ---. Wrap code in backticks to set it in monospace, e.g. B[`GET /api`].
